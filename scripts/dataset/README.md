# 情感AI混合训练集 · 总索引

面向「情感AI大模型」的 SFT 训练集，**总量 5000 条**，按任务与场景分门别类存放于 `data/`，
每行一个标准 JSONL（仅含 `messages` 字段），可直接用于 LLaMA-Factory / ms-swift / Axolotl / OpenAI fine-tuning。

## 一、目录结构
```
data/
├── 01_情绪识别/          # 文本→情绪JSON标注，按14类情绪分文件（2500条）
├── 02_共情对话_单轮/     # 单轮共情回应，按12主题分文件（1501条）
├── 03_共情对话_多轮/     # 多轮共情陪伴，按12主题分文件（750条）
└── 04_语气词专项/        # 语气词近音辨析/情绪适配/克制/软萌（249条）
docs/                     # 语气词使用规范、数据说明
scripts/                  # 生成与合并脚本（可复现/继续扩充）
manifest.json             # 机器可读索引（文件→类别/条数）
```

## 七、数据构成与质量说明
- **手工精选核心**：首批及历次手工编写样本（情绪识别152、共情对话100、语气词56）+ 语气词近音对照82条，质量基准。
- **程序化扩写**：其余由富模板库（多框架×大槽位）组合扩写，固定随机种子（seed=20261113）生成并去重，用于扩充规模与场景覆盖。
- 两类任务以不同 system 提示词区分；共情 system 已注入语气词总原则。
- 建议训练前人工抽检共情质量与安全回应；可按需对某类别加权采样或继续扩充。

## 八、复现与扩充
- 复现：运行 `scripts/build_dataset.py`（依赖 `scripts/` 下模板库与精选样本模块）。
- 扩充：在对应模板库（banks_recognition / banks_dialogue / tone_bank）追加框架或槽位，重跑即可；自动去重、分类、重建索引。
